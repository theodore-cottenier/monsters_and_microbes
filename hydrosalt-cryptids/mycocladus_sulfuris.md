# Scientific Dossier: *Mycocladus sulfuris*

**Common name:** Sulfur Lace  
**Ecosystem role:** Decomposer - Sulfur-film recycler

## Profile

A branching amber filament network with hooked recycling nodules. This cryptid shares the same deep-sea hydrothermal-vent ecosystem as *Hydrosaltator amictus*.

- **Habitat:** dead mineral mats and abandoned shell fragments
- **Type:** Decomposer
- **Role:** Sulfur-film recycler

## Symbiotic relationships

Breaks down spent sulfur films for Saccharoplasma lentus and returns trace minerals to the matrix.

## Field behavior

Turns discarded biofilm into neat lacework, as if the vent hired a grim decorator.
